AEEE ExCom two-page website

Files:
- index.html: homepage only
- apply.html: separate application page
- style.css: shared theme and responsive styling
- script.js: scroll reveals and Formspree background submission
- aeee-logo.png / aeee-logo-white.png: logo assets

Publish all files in the root of the GitHub Pages repository. The homepage Apply buttons link to apply.html. Form submissions use https://formspree.io/f/myekapvb and show a thank-you message only after a successful response.
